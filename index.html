CHAPTER 01

因式分解

代数地基 · 不牢则分式必崩

1.1 概念与判断

把一个多项式化成几个整式的积的形式，叫做因式分解。它是整式乘法的逆变形，属于恒等变形，前后值不变。

(a+b)(a−b) ⇄ a² − b²　左→右：整式乘法；右→左：因式分解

判断一个变形是不是因式分解，看三条：

  • 左边必须是多项式（几个单项式的和）；
  • 右边必须是积的形式，且每个因式都是整式；
  • 必须分解到底（在有理数范围内不能再分）。

反例：x²−1 = x(x − 1/x) 不是，因为 1/x 不是整式；x²+2x+1 = (x+1)² 是；x²−1+2 = x²+1 不是（右边是和）。

1.2 提公因式法

公因式的确定（三步取法）：系数取最大公约数；字母取相同的字母；指数取最低次幂。公因式可以是单项式，也可以是多项式整体。

ma + mb + mc = m(a + b + c)
例：−6a³b² + 9a²b³ − 3a²b² = 3a²b²(−2a + 3b − 1)

三个高频细节：

  • 某项被完全提出时，括号里要留 1，不能空着；
  • 首项为负，习惯先提"−"号，括号内各项全部变号；
  • 公因式是多项式时，注意互为相反数的整体：(a−b)² = (b−a)²，但 (a−b)³ = −(b−a)³。

1.3 公式法

公式结构特征要点
平方差
a²−b²=(a+b)(a−b)		两项、异号、都能写成某式的平方系数是平方数、指数是偶数才可能是平方项
完全平方
a²±2ab+b²=(a±b)²		三项、首末同号且为平方、中间是两底数积的 2 倍中间项符号决定括号内是"+"还是"−"

教材正文以提公因式、公式法为主；十字相乘（x²+px+q，找和为 p、积为 q 的两数）、分组分解、配方法（如 x⁴+4）常作为拓展在习题中出现。

1.4 解题流程与四大应用

一提 → 二套 → 三查 → 四彻底：提公因式 → 试公式 → 查项数是否还能再分 → 结果化为最简积
  • 简便计算：2026²−2025²=(2026+2025)(2026−2025)=4051；
  • 代数式求值：把条件整体代入因式分解后的式子；
  • 整除证明：把式子分解成含某因数的积；
  • 几何应用：面积、周长与整式的关系（如拼图验证公式）。
易错清单
① 分解不彻底：x⁴−1=(x²+1)(x²−1) 还要写成 (x²+1)(x+1)(x−1)；
② 提公因式漏 1：a²+a≠a·a；
③ 符号丢三落四：−x²+4=−(x+2)(x−2)；
④ 把"积化和"当成因式分解；
⑤ 完全平方公式里 2ab 漏乘 2，如把 4x²+6x+9 误判为完全平方式。

经典习题

8 题 · 基础 → 拔高
1-1基础

分解因式：−6a³b² + 9a²b³ − 3a²b²

查看解析
① 定公因式：系数 gcd(6,9,3)=3；字母取 a²b²（最低次幂）。 ② 提出后逐项定商：−6a³b²÷3a²b²=−2a，9a²b³÷3a²b²=3b，−3a²b²÷3a²b²=−1。 答案：3a²b²(−2a + 3b − 1) 提醒：最后一项商是 −1，不能漏写。
1-2基础

分解因式：x³ − 4x；　4x² − 12x + 9

查看解析
（1）先提 x：x(x²−4)，再用平方差：x(x+2)(x−2)。 （2）首末为 (2x)² 与 3²，中间 −12x = −2·2x·3，是完全平方式：(2x−3)²。 答案：x(x+2)(x−2)；　(2x−3)²
1-3基础

分解因式：(a+b)² − 4(a+b) + 4；　3x² − 27

查看解析
（1）把 a+b 看作整体 t：t²−4t+4=(t−2)²，回代得 (a+b−2)²。 （2）先提 3：3(x²−9)=3(x+3)(x−3)。 答案：(a+b−2)²；　3(x+3)(x−3) 考点：整体思想 + 提公因式优先。
1-4中档

分解因式：a⁴ − 8a² + 16

查看解析
① 三看作完全平方式：(a²)² − 2·a²·4 + 4² = (a²−4)²。 ② 括号内还能分解：a²−4=(a+2)(a−2)。 答案：(a+2)²(a−2)² 易错：写成 (a²−4)² 即止，属于"分解不彻底"。
1-5中档

已知 a+b=4，ab=3，求 a²b+ab²、a²+b²、(a−b)² 的值。

查看解析
① a²b+ab² = ab(a+b) = 3×4 = 12 ② a²+b² = (a+b)² − 2ab = 16 − 6 = 10 ③ (a−b)² = a²+b² − 2ab = 10 − 6 = 4 方法：把 a+b、ab 当"整体已知量"，所有对称式都能用它们表示。这是整式与分式化简求值的通用套路。
1-6中档

用简便方法计算：99² + 198 + 1；　2026² − 2026 × 2025

查看解析
（1）99² + 2×99×1 + 1² = (99+1)² = 100² = 10000 （2）提公因式：2026×(2026−2025) = 2026 看到"平方 + 2 倍积 + 1"就想到完全平方；看到"两项含相同因数"就提公因式。
1-7拔高

分解因式：x⁴ + 4

查看解析
① 直接看是"两项和"，既非平方差也无公因式，用配方法造出平方差： x⁴ + 4 = (x⁴ + 4x² + 4) − 4x² = (x²+2)² − (2x)² ② 用平方差：= (x²+2+2x)(x²+2−2x) 答案：(x²+2x+2)(x²−2x+2) 关键：加一项再减一项（加 4x² 减 4x²），凑成完全平方后作差。这两个二次因式在有理数范围内不能再分解。
1-8拔高

（1）证明：对任意整数 n，n³ − n 一定能被 6 整除。
（2）若 x² + kx + 12 能分解为 (x+a)(x+b)（a、b 为整数），求整数 k 的所有可能值。

查看解析
（1）n³−n = n(n²−1) = n(n−1)(n+1) = (n−1)·n·(n+1) 这是三个连续整数的积：其中必有偶数（被 2 整除），也必有 3 的倍数，且 2 与 3 互质，所以积必被 2×3=6 整除。 （2）展开得 a+b=k，ab=12。整数对 (a,b) 有：(1,12)、(2,6)、(3,4) 及全部取负。 对应 k = 13、8、7、−13、−8、−7 答案：k ∈ {±7, ±8, ±13} 这是"十字相乘"的逆向考法，分类要全（正负都算）。
CHAPTER 02

分式与分式方程

全册分值最高 · 计算 + 应用

2.1 分式的概念

形如 A/B（A、B 是整式，B 中含字母且 B≠0）的式子叫分式。判断标准只有一条：分母中是否含字母。

问题条件
分式有意义分母 B ≠ 0
分式无意义分母 B = 0
分式值为 0分子 A = 0 且 分母 B ≠ 0（两者同时满足）
分式值为正/负看分子分母同号/异号，常与不等式结合

2.2 基本性质与变形

A/B = (A·M)/(B·M) = (A÷M)/(B÷M)　（M 是不等于 0 的整式）
  • 约分：分子分母同除以公因式，结果叫最简分式（分子分母没有公因式）。约分前必须先因式分解。
  • 通分：化成分母相同的分式。最简公分母 = 系数的最小公倍数 × 各因式的最高次幂。
  • 符号法则：分子、分母、分式本身三个符号，任改两个，值不变：−A/B = A/(−B) = −(A/B)。
  • 繁分式：用"除法"或"乘以倒数"化简，如 (1+1/x)/(1−1/x) = (x+1)/(x−1)。

2.3 四则运算

运算法则技巧
乘法分子×分子，分母×分母先分解因式、交叉约分，再乘，减少计算量
除法乘除数的倒数：A/B ÷ C/D = A/B · D/C除号变乘号后，把后面整个分式颠倒
乘方(A/B)ⁿ = Aⁿ/Bⁿ负号与括号要分清
加减同分母：分母不变，分子相加减；异分母：先通分分子相减时整体加括号，防止符号错

混合运算顺序：先乘方 → 再乘除 → 最后加减；有括号先算括号内。结果必须化成最简分式或整式。

2.4 分式方程

解法四步：找最简公分母 → 两边同乘，化为整式方程 → 解整式方程 → 验根（代入最简公分母，是否为 0）→ 写结论
  • 增根：使最简公分母为 0 的根。产生原因是去分母时乘了可能为 0 的式子，扩大了未知数的取值范围。
  • 方程无解的两种情况：① 整式方程本身无解；② 解出的根全是增根。
  • 含参问题："方程有增根"→ 令最简公分母为 0 求出增根，再代回整式方程求参数；"方程无解"→ 两种情况都要讨论。

2.5 实际应用：三类模型

类型基本关系常见等量关系
工程工作量 = 效率 × 时间各部分工作量之和 = 1（总量设为 1）
行程时间 = 路程 ÷ 速度时间差、时间相等、往返时间相同
销售单价 = 总价 ÷ 数量数量差、单价倍数、总价差

答题模板：设未知数 → 列表表示各量 → 找等量关系列方程 → 解方程 → 双检验（验根 + 验实际意义）→ 作答。

2.6 化简求值的三种常用技巧

  • 整体代换：已知 1/a − 1/b = 3 这类条件，化为 a−b 与 ab 的关系整体代入；
  • 设 k 法：已知 a/b = 2/3，设 a=2k, b=3k；
  • 先化简后求值：不要一开始就代入数字，先约到最简，再代入，且注意取值要使原式有意义。
易错清单
① 去分母时漏乘不含分母的项（尤其常数项）；
② 忘记验根，把增根当解；
③ 混淆"约分"（化简用）与"去分母"（解方程用）；
④ 值为 0 只看分子，漏掉分母 ≠ 0；
⑤ 应用题结果不检验实际意义（人数、速度、长度不能为负）；
⑥ 化简求值时取了使分母为 0 的值。

经典习题

11 题 · 含 2 道应用题
2-1基础

（1）当 x 取何值时，分式 (x−1)/(x+2) 有意义？值为 0？
（2）当 x 取何值时，分式 (x²−9)/(x−3) 的值为 0？

查看解析
（1）有意义：x+2≠0，即 x≠−2；值为 0：x−1=0 且 x≠−2，即 x=1。 （2）x²−9=0 → x=±3，但 x=3 时分母 x−3=0，分式无意义，故舍去。 答案：x≠−2；x=1；x=−3 "值为 0"必须同时满足"分子=0"和"分母≠0"，这是必考陷阱。
2-2基础

约分：(x²−4)/(x²−4x+4)；　计算：1/(x−1) + 1/(x+1)

查看解析
（1）分子 (x+2)(x−2)，分母 (x−2)²，约去 (x−2)：(x+2)/(x−2)（x≠2）。 （2）通分：[(x+1)+(x−1)]/(x²−1) = 2x/(x²−1)。 答案：(x+2)/(x−2)；　2x/(x²−1)
2-3基础

计算：(a²−1)/a ÷ (a+1)

查看解析
除法转乘法：(a²−1)/a × 1/(a+1) = (a+1)(a−1)/[a(a+1)] 答案：(a−1)/a　（a≠0 且 a≠−1） 整式 (a+1) 的分母看作 1，颠倒后即为 1/(a+1)。
2-4中档

解方程：1/(x−2) = 3/x

查看解析
最简公分母 x(x−2)，两边同乘：x = 3(x−2) 解得 x = 3x − 6 → 2x = 6 → x = 3 检验：x(x−2)=3×1=3≠0，成立。 答案：x = 3
2-5中档

解方程：x/(x−3) − 2 = 3/(x−3)

查看解析
两边同乘 (x−3)：x − 2(x−3) = 3（注意常数 2 也要乘！） x − 2x + 6 = 3 → −x = −3 → x = 3 检验：x=3 时 x−3=0，是增根。 答案：原方程无解 这是最典型的"增根陷阱"：整式方程有解，但解是增根，所以原方程无解。结论必须写"无解"。
2-6中档

解方程：(x+1)/(x−1) − 4/(x²−1) = 1

查看解析
最简公分母 (x+1)(x−1)，两边同乘： (x+1)² − 4 = x² − 1 x² + 2x + 1 − 4 = x² − 1 → 2x − 3 = −1 → x = 1 检验：x=1 时公分母为 0，是增根。 答案：原方程无解
2-7中档

先化简，再求值：(1 − 1/(x+1)) ÷ x/(x²−1)，其中 x = 2。

查看解析
括号内通分：(x+1−1)/(x+1) = x/(x+1) 除法转乘法：x/(x+1) × (x²−1)/x = x/(x+1) × (x+1)(x−1)/x 约分得 x−1；代入 x=2 得 1。 答案：化简为 x−1，值为 1 若题目改成"x 取一个你喜欢的数"，必须避开 x=0、±1 这些使原式无意义的值。
2-8拔高

若关于 x 的方程 (x+m)/(x−2) = 3 有增根，求 m 的值；并说明此时方程的解的情况。

查看解析
① 去分母：x + m = 3(x−2) → x + m = 3x − 6 → 2x = m + 6 ② 所以 x = (m+6)/2。增根必使最简公分母 x−2=0，即 x = 2。 ③ 令 (m+6)/2 = 2，得 m = −2。 答案：m = −2；此时整式方程的解恰为增根，原分式方程无解。 "有增根"求参的关键：增根来自最简公分母为 0，而不是原方程的任意根。
2-9拔高

已知 1/a − 1/b = 3，求 (2a + 3ab − 2b)/(a − 2ab − b) 的值。

查看解析
① 由条件通分：(b−a)/(ab) = 3 → b − a = 3ab → a − b = −3ab ② 分子：2(a−b) + 3ab = 2(−3ab) + 3ab = −3ab ③ 分母：(a−b) − 2ab = −3ab − 2ab = −5ab ④ 原式 = (−3ab)/(−5ab) = 3/5 答案：3/5 技巧：把 a−b 与 ab 看成两个"整体字母"，分子分母都只在用它们表示，ab 最后约掉。
2-10拔高

某工程，甲队单独做需 20 天完成，乙队单独做需 30 天完成。现由乙队先做 5 天，然后两队合做，还需多少天完成？

查看解析
① 设总工作量为 1，甲效率 1/20，乙效率 1/30。 ② 设合做 x 天完成，列方程：5/30 + x(1/20 + 1/30) = 1 ③ 1/6 + x/12 = 1 → x/12 = 5/6 → x = 10 ④ 检验：x=10 符合实际，分母不为 0。 答案：还需合做 10 天 工程问题核心：各段工作量相加 = 1；"先做""中途离开""休息"都是分段累加。
2-11拔高

某文具店用 2000 元购进 A 种钢笔，用 2400 元购进 B 种钢笔，B 种每支进价比 A 种高 2 元，且两种钢笔购进数量相同。
（1）求 A、B 两种钢笔每支的进价；
（2）若 A 种售价 15 元/支，B 种售价 20 元/支，全部售完可获利多少元？

查看解析
（1）设 A 种每支 x 元，则 B 种每支 (x+2) 元。 数量相同：2000/x = 2400/(x+2) 去分母：2000(x+2) = 2400x → 2000x + 4000 = 2400x → 400x = 4000 → x = 10 检验：x=10 时分母不为 0，且符合实际。 答：A 种进价 10 元/支，B 种进价 12 元/支，各购进 200 支。 （2）利润 = 200×(15−10) + 200×(20−12) = 1000 + 1600 = 2600 元。 答案：进价 10 元、12 元；共获利 2600 元
CHAPTER 03

数据分析

概念 + 计算 + 读图（新版变化最大）

3.1 平均数与加权平均数

算术平均数：x̄ = (x₁ + x₂ + … + xₙ) / n
加权平均数：x̄ = (x₁f₁ + x₂f₂ + … + xₖfₖ) / (f₁ + f₂ + … + fₖ)

"权"的三种表现形式：次数（人数、天数）、比例（2:3:5）、百分比（30%、30%、40%）。权的意义是该数据的重要程度，权越大，对平均数的影响越大。

当各权之和为 1 时（百分比形式），可简化为 x̄ = x₁p₁ + x₂p₂ + … + xₖpₖ，不必再除。

3.2 平均数、中位数、众数

统计量定义要点特点
平均数总和 ÷ 个数，用到全部数据信息最全，但怕极端值
中位数排序后中间位置的数；n 为偶数时取中间两数平均只看位置，抗极端值
众数出现次数最多的数据，可以有多个，也可能没有反映"最常见"，不受极端值影响

3.3 方差与标准差

s² = 1/n · [ (x₁−x̄)² + (x₂−x̄)² + … + (xₙ−x̄)² ]　　标准差 s = √(s²)
  • 方差刻画数据的波动大小（离散程度）：方差越小越稳定、越整齐；
  • 变换规律：每个数据都加 a，平均数加 a、方差不变；每个数据都乘 k，平均数乘 k、方差变为 k²s²。

3.4 箱线图与四分位数（新版新增）

五数概括：最小值 — Q₁ — 中位数 Q₂ — Q₃ — 最大值　　四分位距 IQR = Q₃ − Q₁

四分位数的确定（教材法）：数据从小到大排列 → 求中位数把数据分成上下两半 → 下半部分的中位数是 Q₁，上半部分的中位数是 Q₃。

箱线图能读出什么：中间 50% 数据的集中范围（箱体长度 = IQR）、数据的对称性（中位线是否居中）、极端值离群程度（须的长度）。箱体越短，中间数据越集中。

3.5 用样本估计总体 & 统计量选择

  • 用样本平均数估计总体平均水平，用样本方差估计总体波动；
  • 决策类题目："平均数相同看方差，方差相同看趋势（增长/稳定）"，答题必须数据 + 结论 + 理由三件套。
  • 常见情境：有极端值（收入、房价）→ 用中位数；关注"最常见"（鞋码、销量）→ 用众数；关注总量（总产量）→ 用平均数。
易错清单
① 求中位数没排序；
② 加权平均数把"权"当普通数据，或忘除权和；
③ 方差漏平方、漏除 n（初中是 1/n，不是 1/(n−1)）；
④ 只比平均数就下结论，忽略稳定性；
⑤ 箱线图把 Q₁、Q₃ 误认为最小值、最大值；
⑥ 结论题只写数字不写判断，导致"会算不得分"。

经典习题

8 题 · 计算 + 决策
3-1基础

求数据 2, 3, 3, 5, 7 的平均数、中位数、众数、方差。

查看解析
平均数：(2+3+3+5+7)/5 = 20/5 = 4 中位数：已排序，第 3 个数 = 3；众数 = 3 方差：偏差 −2, −1, −1, 1, 3，平方和 4+1+1+1+9 = 16，s² = 16/5 = 3.2 答案：平均数 4，中位数 3，众数 3，方差 3.2

某同学平时成绩 90 分（占 30%）、期中 85 分（占 30%）、期末 88 分（占 40%），求学期总评成绩。

查看解析
x̄ = 90×30% + 85×30% + 88×40% = 27 + 25.5 + 35.2 答案：87.7 分 权重和为 100%，直接用"数据×百分比"相加，不必再除。
3-3基础

10 名同学的引体向上成绩（个）：8, 9, 9, 10, 10, 10, 11, 12, 12, 13。求平均数、中位数、众数。

查看解析
平均数：(8+9+9+10+10+10+11+12+12+13)/10 = 104/10 = 10.4 中位数：n=10 为偶数，取第 5、6 个的平均值 (10+10)/2 = 10 众数：10（出现 3 次，最多） 答案：10.4；10；10
3-4中档

甲、乙两组各 5 名同学的成绩：
甲：10, 9, 11, 10, 10；　乙：8, 12, 10, 10, 10。
哪一组成绩更稳定？说明理由。

查看解析
两组平均数都是 10，需比较方差。 甲：偏差 0, −1, 1, 0, 0，s² = (0+1+1+0+0)/5 = 0.4 乙：偏差 −2, 2, 0, 0, 0，s² = (4+4+0+0+0)/5 = 1.6 答案：甲组更稳定。因为平均数相同，而甲的方差 0.4 ＜ 乙的 1.6，方差越小波动越小。 答题必须"比较方差 + 给出结论 + 说明理由"，只写"甲方差小"会丢分。
3-5中档

数据 1, 3, 5, 7, 9, 11, 13, 15，求中位数、下四分位数 Q₁、上四分位数 Q₃ 及四分位距 IQR。

查看解析
① n=8，中位数 Q₂ = (7+9)/2 = 8 ② 下半部分 1, 3, 5, 7 → Q₁ = (3+5)/2 = 4 ③ 上半部分 9, 11, 13, 15 → Q₃ = (11+13)/2 = 12 ④ IQR = 12 − 4 = 8 答案：Q₂=8，Q₁=4，Q₃=12，IQR=8 IQR 表示"中间 50% 数据的跨度"，是箱体的长度。
3-6中档

为估计鱼塘中鱼的总数，先从塘中捞出 200 条鱼做上标记后放回；待标记鱼完全混合后，再捞出 200 条，发现其中有 8 条带标记。估计鱼塘中鱼的总数。

查看解析

3-7拔高

查看解析

查看解析

CHAPTER 04

图形的平移与旋转

变换 · 作图 + 坐标 + 最短路径

4.1 平移

三要素：平移方向、平移距离。平移由这两者唯一确定。

性质：对应点所连的线段平行（或在同一直线上）且相等；对应线段平行且相等，对应角相等；图形的形状、大小都不变（前后全等）。

坐标规律：向右 a 个单位 (x+a, y)；向上 b 个单位 (x, y+b)，即"左减右加，下减上加"

平移作图三步：定关键点 → 按方向和距离作对应点 → 顺次连线，写出结论。

4.2 旋转

三要素：旋转中心、旋转方向（顺/逆时针）、旋转角。

性质：① 对应点到旋转中心的距离相等；② 对应点与旋转中心连线所成的角都等于旋转角；③ 对应线段相等、对应角相等；④ 前后图形全等。

找旋转中心：作两组对应点连线的垂直平分线，交点即为旋转中心。

绕原点旋转 90°：逆时针 (x, y) → (−y, x)；顺时针 (x, y) → (y, −x)
绕原点旋转 180°：(x, y) → (−x, −y)

4.3 中心对称与中心对称图形

概念含义举例
中心对称一个图形绕某点旋转 180° 后与另一个图形重合（两个图形的关系）成中心对称的两个三角形
中心对称图形一个图形绕自身某点旋转 180° 后与自身重合平行四边形、圆、正六边形、线段

性质：对称中心是对应点连线的中点，对应线段平行（或在同一直线）且相等。注意：等边三角形、正五边形是轴对称图形，不是中心对称图形。

4.4 最短路径两模型

模型作法
将军饮马
同侧两点到直线上一点距离和最小		作其中一点关于直线的对称点，连接对称点与另一点，与直线的交点即为所求点
造桥选址
两平行线间修垂直于河岸的桥		把一点沿垂直河岸方向平移桥长，连接平移后的点与另一点，交河岸于桥的一端，再过该点作垂线

两模型的本质相同：用对称或平移把"折线"拉直，再用"两点之间线段最短"。

易错清单
① 平移距离指对应点连线的长度，不是图形"看上去移动的横向距离"；
② 旋转角是对应点与旋转中心连线的夹角，不是图形外观转过的角度；
③ 旋转方向搞反；量角时顶点没对准旋转中心；
④ 作图后对应点标错，导致后面证全等时对应关系混乱；
⑤ 求最值忘记写依据"两点之间线段最短"；
⑥ 混淆"中心对称"（两个图形）与"中心对称图形"（一个图形自身）。

经典习题

8 题 · 含作图与最值
4-1基础

（1）点 A(2, −3) 先向右平移 4 个单位，再向下平移 2 个单位，求对应点坐标；
（2）点 P(−1, 2) 绕原点顺时针旋转 90°，求对应点坐标。

查看解析
（1）右移 4：x → 2+4 = 6；下移 2：y → −3−2 = −5，得 (6, −5)。 （2）顺时针 90°：(x, y) → (y, −x)，即 (2, 1)。 答案：(6, −5)；　(2, 1) 记不牢时用"画图试一个点"验证：P 在第二象限，顺时针转 90° 应落到第一象限，(2,1) 符合。
4-2基础

线段 AB 经过平移后，点 A(1, 2) 的对应点为 A′(4, 6)。若 B(3, −1)，求 B′ 的坐标。

查看解析
先求平移量：(4−1, 6−2) = (+3, +4)，即右移 3、上移 4。 同一平移下所有点位移相同：B′ = (3+3, −1+4) = (6, 3) 答案：B′(6, 3) 平移的"整体性"：每个点都移动同样的向量，这是所有平移计算题的钥匙。
4-3基础

下列图形中，是中心对称图形的有：① 平行四边形　② 等边三角形　③ 圆　④ 正五边形　⑤ 正六边形　⑥ 线段

查看解析
判定方法：能否找到一点，绕它旋转 180° 后与自身重合。 平行四边形（对角线交点）、圆（圆心）、正六边形（中心）、线段（中点）都满足。 等边三角形、正五边形旋转 180° 后方向反了，不重合——它们是轴对称图形。 答案：①③⑤⑥ 规律：正 n 边形中，n 为偶数时是中心对称图形，n 为奇数时不是。
4-4中档

把 △ABC 绕点 A 顺时针旋转 60° 得到 △ADE。已知 AB = 3，∠BAC = 40°。
（1）求 AD 的长；（2）求 ∠BAD 与 ∠CAE 的度数。

查看解析
（1）旋转前后图形全等，对应线段相等：AD = AB = 3 （2）B 的对应点是 D，所以 ∠BAD 就是旋转角 = 60° C 的对应点是 E，同理 ∠CAE = 60° 答案：AD = 3；∠BAD = 60°，∠CAE = 60° "对应点与旋转中心连线的夹角 = 旋转角"，每个对应点对都给出同一个旋转角，这是旋转计算的核心依据。
4-5中档

在平面直角坐标系中，A(0, 2)，B(4, 4)，点 P 在 x 轴上。当 PA + PB 最小时，求点 P 的坐标及最小值。

查看解析
① 作 A 关于 x 轴的对称点 A′(0, −2)，则 PA = PA′，问题转为 PA′ + PB 最小。 ② 当 A′、P、B 三点共线时和最小，此时最小值为 A′B。 ③ 直线 A′B 过 (0,−2)、(4,4)，斜率 = 6/4 = 3/2，即 y = 3x/2 − 2。 ④ 令 y = 0：3x/2 = 2 → x = 4/3，故 P(4/3, 0)。 ⑤ A′B = √(4² + 6²) = √52 = 2√13 答案：P(4/3, 0)，最小值 2√13 将军饮马三步：找对称点 → 连直线 → 求交点。最小值就是对称点与另一点的距离。
4-6中档

说明"把 △ABC 绕点 O 逆时针旋转 90°"的作图步骤。

查看解析
① 连接 OA，以 O 为顶点、OA 为一边，逆时针作 ∠AOA′ = 90°，并在射线上截取 OA′ = OA，得点 A′。 ② 同法作出 B′、C′（保证 OB′ = OB，OC′ = OC，旋转角都是 90°）。 ③ 顺次连接 A′B′、B′C′、C′A′，△A′B′C′ 即为所求。 依据：对应点到旋转中心的距离相等 + 旋转角相等。三个顶点都按同一规则处理，答案要写全三步，缺一扣分。
4-7拔高

△ABC 的面积为 8，将它沿 BC 方向平移，平移距离等于 BC 的长，得到 △DCE（B、C、E 在同一直线上，A 的对应点为 D）。求四边形 ABED 的面积。

查看解析
① 由平移性质：AB ∥ DE 且 AB = DE，所以四边形 ABED 是平行四边形。 ② BE = BC + CE = 2BC，而平行四边形 ABED 与 △ABC 同高（都以 BC 所在直线为底边所在直线）。 ③ SABED = BE × h = 2BC × h = 2 × (½·BC·h) = 2 × 8 = 16 答案：16 平移后常出现"等底同高"或"底翻倍"的面积关系，先找出平行四边形，再用面积公式比。
4-8拔高

△ABC 的三个顶点为 A(1,1)、B(4,1)、C(3,3)。将它绕原点 O 逆时针旋转 90°，得到 △A′B′C′。
（1）写出 A′、B′、C′ 的坐标；（2）求 △A′B′C′ 的面积。

查看解析
（1）逆时针 90°：(x,y) → (−y, x) A(1,1) → A′(−1,1)；B(4,1) → B′(−1,4)；C(3,3) → C′(−3,3) （2）原三角形：AB = 3（水平），C 到 AB 的距离 = 3−1 = 2，S = ½×3×2 = 3。 旋转不改变图形形状和大小，所以 S′ = 3。 答案：A′(−1,1)、B′(−1,4)、C′(−3,3)；面积 3 旋转前后全等，面积直接沿用，不必重新算——这是最省时的做法，但要在答卷上写明"旋转不改变图形大小"。
CHAPTER 05

四边形

几何证明主战场 · 性质 + 判定 + 辅助线

5.1 平行四边形的性质

  • 边：对边平行且相等；
  • 角：对角相等，邻角互补（和为 180°）；
  • 对角线：两条对角线互相平分；
  • 对称性：是中心对称图形（对称中心为对角线交点），一般不是轴对称图形；
  • 面积：S = 底 × 高；一条对角线把它分成两个全等三角形，两条对角线分成四个面积相等的三角形。

5.2 平行四边形的判定（五种）

序号判定方法常见用法
①两组对边分别平行定义法，已知平行时用
②两组对边分别相等已知长度关系
③一组对边平行且相等最常用，平行 + 相等一步到位
④两组对角分别相等角度条件题
⑤对角线互相平分出现中点、中线时首选
反例警告
"一组对边平行、另一组对边相等"不能判定平行四边形——等腰梯形就是反例（AD∥BC，AB = CD，但不是平行四边形）。

5.3 三角形的中位线

连接三角形两边中点的线段叫中位线；它平行于第三边，且等于第三边的一半：DE ∥ BC，DE = ½BC

证明思路（必会）：延长 DE 到 F 使 EF = DE，连 CF。由 AE = EC、对顶角相等、DE = EF 得 △ADE ≌ △CFE，从而 CF ∥ AD 且 CF = AD = BD，故四边形 DBCF 是平行四边形，得 DF ∥ BC、DF = BC，即 DE ∥ BC 且 DE = ½BC。

一句话记法：倍长中线（中位线）造平行四边形——这是八年级上册最常用的辅助线。

5.4 梯形

  • 定义：只有一组对边平行的四边形。平行的两边叫底（上底、下底），另两边叫腰。
  • 等腰梯形：两腰相等；同一底上的两个角相等；两条对角线相等；是轴对称图形。
  • 梯形中位线：连接两腰中点的线段，平行于两底，且等于两底和的一半：m = (a + b)/2。
  • 面积：S = (a + b) × h ÷ 2 = m × h

四条常用辅助线（把梯形"化"成三角形或平行四边形）：

辅助线作法与作用
作高过两底端点作高，分成两个直角三角形 + 一个矩形；用于求高、求底
平移一腰过一顶点作另一腰的平行线，把两腰、两底之差集中到一个三角形
延长两腰两腰延长交于一点，得到两个相似/等腰三角形（上底∶下底 = 相似比）
平移对角线过一顶点作对角线的平行线，把两条对角线与两底之和集中到一个三角形

5.5 多边形的内角和与外角和

n 边形内角和 = (n − 2) × 180°；任意多边形的外角和恒为 360°
正 n 边形：每个内角 = (n−2)×180°/n，每个外角 = 360°/n

内角和公式的由来：从一个顶点出发连对角线，把 n 边形分成 (n−2) 个三角形。

5.6 平面镶嵌（综合与实践）

  • 条件：拼在同一顶点处的各内角之和恰好等于 360°，且不留缝隙、不重叠；
  • 能单独镶嵌的正多边形只有正三角形（60°）、正方形（90°）、正六边形（120°）；正五边形（108°）不行；
  • 组合镶嵌：如正十二边形（150°）+ 两个正三角形（60°×2）+ 正十二边形（150°）= 360°；
  • 任意三角形、任意四边形都能单独镶嵌（内角和分别为 180°、360°，可拼成 360°）。
易错清单
① 把"对角线相等""四个角都是直角"当成平行四边形的性质（那是矩形）；
② 判定时条件写不全，如"对边相等"必须"两组"；
③ 混淆中位线（两中点连线）与中线（顶点与对边中点连线）；
④ 梯形题不作辅助线硬算；作高后忘记说明得到的是矩形；
⑤ 证明跳步：由平行直接得相等，不写依据"平行四边形对边相等"；
⑥ 多边形内角和与外角和公式混用。

经典习题

9 题 · 计算 + 证明
5-1基础

▱ABCD 中，∠A : ∠B = 1 : 2，求四个内角的度数；若 AB = 5，AD = 8，求周长。

查看解析
邻角互补：∠A + ∠B = 180°，而 ∠A:∠B = 1:2，故 ∠A = 60°，∠B = 120°。 对角相等：∠C = ∠A = 60°，∠D = ∠B = 120°。 周长 = 2(AB + AD) = 2×(5+8) = 26 答案：60°、120°、60°、120°；周长 26
5-2基础

▱ABCD 的对角线交于点 O，AC = 10，BD = 6，AB = 7。求 OA + OB 及 △AOB 的周长。

查看解析
对角线互相平分：OA = ½AC = 5，OB = ½BD = 3，故 OA + OB = 8。 △AOB 周长 = OA + OB + AB = 5 + 3 + 7 = 15 答案：8；15 凡是给"对角线长"的平行四边形题，第一步就是折半——这是最高频的起手式。
5-3基础

（1）一个多边形的内角和是外角和的 3 倍，求它的边数；
（2）正十二边形的每个内角是多少度？每个外角呢？

查看解析
（1）外角和为 360°，内角和 = 3×360° = 1080°，由 (n−2)×180° = 1080° 得 n − 2 = 6，n = 8。 （2）每个外角 = 360°/12 = 30°，每个内角 = 180° − 30° = 150°。 答案：八边形；150°、30° 求正多边形内角，先用外角更快：内角 = 180° − 360°/n。
5-4中档

四边形 ABCD 中，AD ∥ BC。添加下列哪个条件后，不能判定它是平行四边形？
A. AD = BC　B. AB ∥ CD　C. AB = CD　D. ∠A = ∠C

查看解析
A：一组对边平行且相等 → 能判定（判定③）。 B：两组对边分别平行 → 能判定（判定①）。 D：AD∥BC → ∠A+∠B=180°，又 ∠A=∠C，得 ∠C+∠B=180° → AB∥CD，能判定。 C：一组对边平行、另一组对边相等，可能是等腰梯形，不能判定。 答案：C
5-5中档

△ABC 中，D、E 分别是 AB、AC 的中点。
（1）若 BC = 8，求 DE；（2）若 DE = 5，求 BC；（3）若 △ADE 的周长为 12，求 △ABC 的周长。

查看解析
（1）DE = ½BC = 4 （2）BC = 2DE = 10 （3）AD = ½AB，AE = ½AC，DE = ½BC，所以 C△ADE = ½C△ABC，即 C△ABC = 24。 答案：4；10；24 中位线把三角形"整体缩小一半"，周长、边长都成比例，这个结论在填空选择里可直接用。
5-6中档

等腰梯形 ABCD 中，AD ∥ BC，AD = 4，BC = 10，腰 AB = CD = 5。求梯形的高和面积。

查看解析
① 平移一腰：过 D 作 DE ∥ AB 交 BC 于 E，则 ABED 是平行四边形，BE = AD = 4，DE = AB = 5。 ② 于是 EC = 10 − 4 = 6，△DEC 三边为 5、5、6（等腰三角形）。 ③ 作 △DEC 底边的高，则半底 = 3，高 = √(5² − 3²) = 4，即梯形的高为 4。 ④ S = (4 + 10) × 4 ÷ 2 = 28 答案：高 4，面积 28 "平移一腰"把两腰和两底之差(10−4=6)凑成一个三角形，3-4-5 直角三角形随之出现。
5-7拔高

四边形 ABCD 中，E、F、G、H 分别是 AB、BC、CD、DA 的中点。求证：四边形 EFGH 是平行四边形。

查看解析
证明：连接 AC。 在 △ABC 中，E、F 分别是 AB、BC 的中点，由三角形中位线定理：EF ∥ AC，EF = ½AC。 在 △ADC 中，同理 HG ∥ AC，HG = ½AC。 所以 EF ∥ HG 且 EF = HG，由"一组对边平行且相等的四边形是平行四边形"，得 EFGH 是平行四边形。 结论成立（这个结论对任意四边形都成立） 关键动作：连对角线，让中位线"有三角形可依附"。看到"各边中点"必连对角线。
5-8拔高

▱ABCD 中，E、F 是对角线 BD 上的两点，且 BE = DF。求证：四边形 AECF 是平行四边形。

查看解析
证法一（对角线互相平分）：设 AC 与 BD 交于点 O。 因为 ABCD 是平行四边形，所以 OA = OC，OB = OD。 又 BE = DF，所以 OB − BE = OD − DF，即 OE = OF。 四边形 AECF 中，OA = OC 且 OE = OF，对角线互相平分，故 AECF 是平行四边形。 证法二（一组对边平行且相等）：由 AB ∥ CD 得 ∠ABE = ∠CDF；又 AB = CD，BE = DF，故 △ABE ≌ △CDF（SAS），得 AE = CF，∠AEB = ∠CFD，从而 ∠AEF = ∠CFE，AE ∥ CF，所以 AECF 是平行四边形。 两种解法都要会：有对角线交点时走"互相平分"最快；没有交点时走"全等 + 平行且相等"。
5-9拔高

△ABC 中，AD 平分 ∠BAC，BD ⊥ AD 于点 D，E 是 BC 的中点。若 AB = 6，AC = 10，求 DE 的长。

查看解析
① 延长 BD 交 AC 于点 F。 ② 在 △ABF 中，AD 平分 ∠BAF 且 AD ⊥ BF，所以 △ABF 是等腰三角形：AF = AB = 6，且 D 是 BF 的中点。 ③ 于是 FC = AC − AF = 10 − 6 = 4。 ④ 在 △BCF 中，D 是 BF 中点、E 是 BC 中点，所以 DE 是中位线，DE = ½FC = 2。 答案：DE = 2 "角平分线 + 垂线"是经典组合：延长垂线必得等腰三角形，再把所求线段放进另一个三角形当地中位线。
CHAPTER 06

综合与压轴

跨章 · 3 道大题

综合题

期末压轴常见类型
6-1压轴

点 B、C、D 在同一条直线上，△ABC 与 △CDE 都是等边三角形。求证：AD = BE，并求 AD 与 BE 所夹锐角的度数。

查看解析
① 证全等：∠ACB = 60°，∠DCE = 60°，故 ∠ACD = 180° − 60° = 120°，∠BCE = 180° − 60° = 120°。 又 AC = BC，CD = CE，所以 △ACD ≌ △BCE（SAS）。 ② 由全等得 AD = BE（对应边相等）。 ③ 设 AD 与 BE 交于点 P。由全等得 ∠CAD = ∠CBE，在 △ 中通过"三角形内角和"可推出 ∠APB = 60°。 答案：AD = BE；所夹锐角为 60° 这就是"手拉手模型"：两个共顶点的等边三角形，把其中一个绕公共点旋转 60° 就能与另一部分重合，必产生一对全等三角形。结论可记：手拉手，必全等；夹角等于旋转角。
6-2压轴

学校用 1200 元购进甲种图书，用 800 元购进乙种图书。甲种每本比乙种贵 4 元，且两种图书购进的数量相同。
（1）求甲、乙两种图书每本的进价；
（2）若学校计划再购进甲、乙两种图书共 60 本，且总费用不超过 700 元，问甲种图书最多能买多少本？

查看解析
（1）设乙种每本 x 元，则甲种每本 (x+4) 元。数量相同： 1200/(x+4) = 800/x 交叉相乘：1200x = 800(x+4) → 1200x = 800x + 3200 → 400x = 3200 → x = 8 检验：x=8 时分母不为 0，且 1200/12 = 800/8 = 100（本），符合题意。 答：甲种每本 12 元，乙种每本 8 元。 （2）设买甲种 m 本，则乙种 (60 − m) 本： 12m + 8(60 − m) ≤ 700 → 12m + 480 − 8m ≤ 700 → 4m ≤ 220 → m ≤ 55 答案：甲种最多买 55 本 第（1）问是分式方程（必须验根），第（2）问是一元一次不等式；两问拼接是期末压轴的标准结构，别把两问的方法混用。
6-3压轴

▱ABCD 中，AB = 5，AD = 8，∠ABC 的平分线交 AD 于点 E。求 DE 的长。

查看解析
① BE 平分 ∠ABC，所以 ∠ABE = ∠EBC。 ② AD ∥ BC，所以 ∠AEB = ∠EBC（内错角相等）。 ③ 于是 ∠ABE = ∠AEB，△ABE 是等腰三角形，AE = AB = 5。 ④ DE = AD − AE = 8 − 5 = 3 答案：DE = 3 模型总结：平行四边形 + 角平分线 → 等腰三角形（"平行 + 平分 → 等腰"）。这是选择填空的高频套路，几乎每年都考。
